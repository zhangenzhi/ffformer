## 4.1 怎么跟 Claude Code 提要求(提示词)

对**已有项目**,先让它读、再让它改。具体、分点写效果最好:

**先摸清结构:**
```
先读一下 deploy/ 目录,给我讲一下这个网页服务的整体结构:
入口在哪、前端页面是哪、任务怎么投到超算、结果怎么回来。
```

**再让它改(举例):**
```
在 dashboard.html 的进度条上加一个「取消」按钮:
- 点了调用后端 POST /task/{id}/cancel
- 显示"取消中…",取消完提示一下
改完帮我 node --check 一下内联 JS。
```

**提要求的诀窍**:① 改什么、② 涉及哪些文件(不确定就让它先找)、③ 要满足的条件(比如"改完做语法检查")分开写。

## 4.2 看懂应用的结构

本项目前台是一个 **FastAPI 网页服务**。主要文件:

| 文件 | 作用 |
|---|---|
| `deploy/server.py` | 服务主体(FastAPI):所有网页接口(上传、任务状态、结果、分析等) |
| `deploy/dashboard.html` | 网页前端(单页,内联 JS + 3D 查看器) |
| `deploy/auth.py` | 登录/账号 |
| `deploy/hpc_backend.py` | 通过 SSH 把任务投到超算、传数据、取结果 |
| `deploy/hpc_run_task.py` | **在超算上**跑的分割推理脚本 |
| `deploy/hpc_llm.py` / `deploy/tree_analysis.py` | LLM/VLM 分析(场景、单树) |
| `deploy/inference_engine.py` | 推理引擎封装 |
| `deploy/Dockerfile` / `deploy/entrypoint.sh` | 打镜像 / 启动(启动时 git pull 最新代码) |

> 不懂哪块,直接问:`把 deploy/hpc_backend.py 里任务是怎么投到超算、结果怎么下载的,用初学者能懂的话讲一遍`。

## 4.3 本机先跑起来看看

改完、部署前,先在本机试跑。这是个 Python 服务,用 uvicorn 启动:

```bash
# 装依赖(第一次)
pip install -r requirements.txt        # 或按项目说明装

# 本地启动(用本地/占位后端,不连超算)
export INFERENCE_BACKEND=local
export RESULTS_DIR=/tmp/ffformer_results
uvicorn deploy.server:app --host 0.0.0.0 --port 8000
```

启动后浏览器开 `http://localhost:8000`,能看到登录/仪表盘页面就说明前台跑起来了。

> **注意**:完整推理要 GPU 和模型权重;本机通常只验证**网页/前端逻辑**是否正常。真正的分割/LLM 跑在超算后端(`INFERENCE_BACKEND=hpc`,部署到研究云后才连得上)。

## 4.4(可选)从零建一个新应用

如果你要建的是**全新**应用而不是改本项目,单独有一章完整走一遍"从零到上线":见 **[4.5 From Zero to End App](04.5-from-zero-to-end-app.md)**。那里用一个轻量示例把"生成 → 容器 → 推仓库 → K8s 部署 → 访问 → 更新"一条龙讲清。

> 提示:新应用记得让端口读环境变量 `PORT`、加个健康检查端点(如 `GET /healthz`)——上 K8s 时要用。本项目对应的是 `PORT`/`8000` 与 `/health`。
