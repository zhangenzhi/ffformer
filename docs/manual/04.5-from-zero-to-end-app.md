## 0. 这个 app 是什么

**JPeaks-Forest 仪表盘**是整个平台的"店面":用户在这个网页上传点云、跑分割、看 3D 结果、读 LLM 分析。技术上很朴素:

| 部分 | 实际是什么 |
|---|---|
| 前端 | **单页** `deploy/dashboard.html`(3000+ 行,**内联** CSS+JS,无构建步骤) |
| 3D 查看器 | **Three.js r128**(CDN)+ 自制**八叉树(octree)流式**点云查看器 |
| 三个页 | **Import**(上传/管理数据)、**Segment**(跑分割+看进度+看 3D 结果)、**Analyze**(LLM 场景分析 + 单树健康) |
| 后端 | **FastAPI** `deploy/server.py`(全部接口)+ `deploy/hpc_backend.py`(把重活投到超算) |

> **一句话架构**:dashboard 是很薄的前台,GPU 分割和 LLM 都跑在超算后端([00 全体像](00-はじめに-全体像.md))。

## 1. 和 Claude Code 一轮轮堆出来

这个 app **不是一次写成**,而是在 `<YOUR_NAME>/ffformer` 目录里跑 `claude`,**一块功能一块功能地加**。下面是真实的推进顺序和提要求方式。

### 1.1 起步:先要一个单页骨架

```
做一个单页仪表盘 dashboard.html:顶部 logo,三个页签 Import / Segment / Analyze。
纯单文件、内联 CSS 和 JS,不要构建步骤。风格简洁深色。
```
先有个能打开的空壳,再往里塞东西。

### 1.2 一块块加功能

按下面的顺序,一轮一个功能。每一轮都是"描述需求 → Claude 改 → 本机看 → 不对再说":

**① 登录 / 账号**
```
加一个登录页:未登录只显示登录卡,登录后才进主界面。
后端 deploy/server.py 用简单的账号系统(注册/登录/登出)。
```

**② Import 页:上传数据**
```
Import 页:让用户选 LAS/LAZ 文件。
在浏览器里先读文件头(前 400 字节)显示点数/范围,再上传;
大文件走导入到超算的接口 /import。
```

**③ Segment 页:跑分割 + 实时进度**
```
Segment 页:点一个按钮把选中的数据投去分割。
显示实时进度条(从后端 /task/{id}/status 轮询),
分割过程中每完成一个瓦片就先渲染出来(增量预览)。
```

**④ 3D 点云查看器(流式)**
```
在 Segment 页加 Three.js 点云查看器:
从 /viewer/{task}/metadata.json 读八叉树元数据,按需拉 /viewer/{task}/tiles/*.bin,
流式加载——只显示子采样,别一次性拉几 GB 的 PLY。
支持按语义/实例上色、调点大小。
```

**⑤ Analyze 页:LLM 分析**
```
Analyze 页:展示整片林子的 LLM 场景分析(stand-level),
以及点单棵树时的健康分析(per-tree)。
接口投到超算后端 hpc_backend.py 上的 LLM 作业。
```

**⑥ 之后的打磨**(都是同样的一轮一改):媒体库(结果从超算重建)、取消按钮、模型切换、查看器加载指示、报告卡片排版……

> **提要求的诀窍**:① 改哪个页/文件、② 要什么行为、③ 附带约束(如"改完 `node --check`")分开写。不确定文件在哪,就先让它"读 `deploy/` 讲结构"。

### 1.3 关键设计决策(真实经验)

- **单页 + 内联 JS**:整个前端就一个 `dashboard.html`,烤进镜像即走,**无需前端构建**。代价——**改完内联 JS 必须 `node --check`**(一个撇号写进字符串就能让整段脚本挂掉,整页 JS 全废)。
- **八叉树流式查看器**:大点云不整包下发,只拉子采样瓦片,几秒出画面;而不是把几 GB 的 PLY 塞进浏览器把它卡死。
- **薄前台 + 重后端**:dashboard 只管交互和展示,分割/LLM 这些 GPU 活全甩给超算,前台不装 GPU。

### 1.4 改起来为什么快

因为镜像 `/app` 是 git 仓库、启动时会 `git pull`,**改 dashboard 不用重打镜像**:
```
改 dashboard.html / server.py  →  node --check(内联 JS 改过就查)
   →  git push origin main  →  kubectl rollout restart(新 pod 自动拉最新代码)
```
几十秒就更新完。这一步的细节(和回滚)见 [10](10-更新とトラブル対処.md)。

### ✔ 确认点

- ☐ 让 Claude Code 讲清 `dashboard.html` 三个页 ↔ `server.py` 接口的对应
- ☐ 改内联 JS 后 `node --check` 通过
- ☐ 本机 `uvicorn deploy.server:app --port 8000` 起得来,浏览器能开三个页签
